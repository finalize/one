# One

Mac のメニューバーに住む、小さな道具をひとつにまとめたアプリ。

- **英かなの切り替え** … 左の ⌘ を単独で押すと英数、右の ⌘ でかなになる
- **ウィンドウを並べる** … ⌃⌥← などのキーや、画面の端へのドラッグで、半分・1/3・1/4 に並べる
- **鏡** … MacBook のノッチをクリックすると、カメラの映像が鏡として出る
- **カレンダー** … メニューバーの ⌘ を押すと、カレンダー.app の予定が入った月の表が出る
- **モニタ** … メニューバーに、ネットワークの速度・CPU・メモリ・ディスクの空きを出す

```
 ↓ 1.2 MB/s  CPU 12%     空き 213 GB        ← メニューバーの One（数字を出しているとき。出さなければ ⌘）
 ↑  30 KB/s  メモリ 61%
```

Dock にも ⌘Tab にも出ない。macOS 14 以降、Apple シリコンでも Intel でも動く。

## 入れる

[Releases](https://github.com/finalize/one/releases/latest) から `One-<版>.zip` を落とす。

1. zip を開き、出てきた `One.app` を **Finder で**「アプリケーション」フォルダへ移す。まだ開かない
2. ターミナルを開き、次の2行を打つ:

   ```sh
   xattr -dr com.apple.quarantine /Applications/One.app
   open /Applications/One.app
   ```

3. アクセシビリティの許可を求められるので与える（下の「許可」）

メニューバーに ⌘ が出れば入っている。

**2 は飛ばせない。** One は Apple の公証（有料の事前の検査）を通していないので、ブラウザで落としたまま開くと
「“One”は開いていません」「検証できませんでした」と止められる。2 の1行目は、ブラウザが付けた
「インターネットから来た」印を外すもので、印の無いアプリは止められない。システム設定の「このまま開く」で
通す方法もあるが、ボタンが出ないことがある。

止められたときに「ゴミ箱に入れる」を押してしまったら、zip を開き直して 1 からやり直す。

### 新しい版に入れ替える

⌘ を右クリックして「One を終了」を選び、`/Applications/One.app` を新しいものに置き換えて、2 をもう一度やる。
許可も設定もそのまま残る。

### LR から移る

0.4.0 までは LR という名前だった。LR の許可と設定は One に引き継がれない。

1. LR を終了し、`/Applications/LR.app` をゴミ箱に入れる。残しておくと、⌘ を押すたびに2つが反応する
2. 上の手順で One を入れ、許可を与える
3. 左右の入れ替えなどの設定は初期値に戻っているので、設定の窓で選び直す
4. ログイン時に起動していたなら、システム設定 > 一般 > ログイン項目 から LR を外し、
   One の設定の「一般」で「ログイン時に起動」を入れる

システム設定のアクセシビリティの一覧に残った LR は、選んで「−」で消してよい。

### Kagami から移る

鏡は、もとは Kagami という別のアプリだった。Kagami を終了して `/Applications/Kagami.app` を消す。
両方が動いていると、ノッチのクリックをどちらが拾うか決まらない。鏡の大きさ・カメラ・画質とカメラの許可は、
One で選び直す。

## 許可

One は3つの許可を使う。どれも初めて要るときに macOS が聞いてくる。

| 許可 | 何に使うか | 聞かれるとき |
| --- | --- | --- |
| アクセシビリティ | ⌘ の単独押しを見る。ほかのアプリのウィンドウを動かす | 初めて起動したとき |
| カメラ | 鏡 | 初めて鏡を開いたとき |
| カレンダー（フルアクセス） | 予定を月の表に並べる。読むだけで、書き換えない | 初めてカレンダーを開いたとき |

アクセシビリティは、ダイアログの「システム設定を開く」を押し、出てきた一覧の One のスイッチを入れる。
アプリを入れ直す必要は無く、入れたらすぐ効く。ダイアログを閉じてしまったら、⌘ を右クリックして
「アクセシビリティ設定を開く…」から同じところに行ける。

今どの許可があるかは、設定の窓の「一般」タブで分かる。

## メニューバーの ⌘

- **左クリック** … カレンダー
- **右クリック**（か control + クリック）… メニュー

モニタの数字をメニューバーに出しているときは、⌘ の代わりに数字が出る。数字を押しても同じように動く。
この README で「⌘ を押す」と書いているところは、そのときは数字を押す。

メニューには、モニタの数字（細かい版）、「ウィンドウ」（並べる操作）、「鏡を出す」、「設定…」（`⌘,`）、
「One を終了」が並ぶ。左右は入れ替えられる（設定の「カレンダー」タブ）。

⌘（か数字）にポインタを載せると、メニューバーに出ている数字の細かい版が出る。

## 英かなを切り替える

```
左 ⌘ を押して離す  →  英数（ABC など）
右 ⌘ を押して離す  →  かな（ひらがな）
```

- `⌘C` や `⌘⇧4` のように、⌘ を押している間にほかのキーやクリックが挟まったら切り替えない
- 英数側とかな側は、入っている入力ソースから選ぶ。かな側は「日本語を扱う入力モード」を探すので、
  ことえり以外の日本語入力でも選ばれる（確かめたのはことえり）。どれが選ばれたかは設定の「英かな」タブで見られる
- 左右を入れ替えられる（設定の「英かな」タブ）
- メニューバーに今のモード（A / あ）も出せる。macOS の入力メニューを消している人向け（設定の「英かな」タブ）

**⌘英かな** のような、同じことをするアプリと一緒に動かさない。1回の ⌘ に両方が反応する。

## ウィンドウを並べる

### キーで

手前のアプリのウィンドウを、キー1つで決まった場所へ動かす。キーは [Rectangle](https://rectangleapp.com/) の既定と同じ。
⌘ の右クリックのメニューの「ウィンドウ」からも選べ、そこに各操作のキーも出ている。

| キー | 操作 |
| --- | --- |
| `⌃⌥←` `⌃⌥→` `⌃⌥↑` `⌃⌥↓` | 左 / 右 / 上 / 下半分 |
| `⌃⌥U` `⌃⌥I` `⌃⌥J` `⌃⌥K` | 左上 / 右上 / 左下 / 右下 |
| `⌃⌥D` `⌃⌥F` `⌃⌥G` | 左 / 中央 / 右 1/3 |
| `⌃⌥E` `⌃⌥R` `⌃⌥T` | 左 / 中央 / 右 2/3 |
| `⌃⌥↩` | 最大化 |
| `⌃⌥⇧↑` | 高さだけ最大化 |
| `⌃⌥C` | 中央へ（大きさはそのまま） |
| `⌃⌥=` `⌃⌥-` | 大きく / 小さく |
| `⌃⌥⌫` | 元に戻す |
| `⌃⌥⌘←` `⌃⌥⌘→` | 前 / 次の画面へ |

- 1/3 を3つ並べても、隙間も重なりも出ない
- **元に戻す**は、One が最初に動かす前の位置に戻る。左半分 → 右 1/3 → 最大化 と続けても、戻り先は最初の位置。
  One が置いたあとに手で動かしていたら、そこを新しい出発点にする
- **次の画面へ**は、画面の中の割合を保って移す。左半分にあったウィンドウは、移した先でも左半分
- **大きく・小さく**では、画面の端に付いた辺は動かさない。1回に 30pt
- 縦長の画面では、1/3 と 2/3 が上下に分かれる
- 動かせないとき（ウィンドウが無い、フルスクリーン、など）はビープが鳴る

### ドラッグで

ウィンドウのタイトルバーを掴んで画面の端へ持っていくと、どこへ並ぶかが半透明の枠で出る。そのまま離せば並ぶ。

```
┌─────────────┬──────────────────────┬─────────────┐
│ 左上の角     │ 上の辺                │ 右上の角     │
│ → 左半分     │ → 中央 1/3           │ → 右半分     │
├─────────────┘                      └─────────────┤
│ 左の辺                                  右の辺    │
│ → 左 1/3                               → 右 1/3  │
├─────────────┐                      ┌─────────────┤
│ 左下の角     │ 下の辺                │ 右下の角     │
│ → 左下       │ → 左・中央・右の 1/3  │ → 右下       │
└─────────────┴──────────────────────┴─────────────┘
```

- **下の辺**は、カーソルの位置で左・中央・右の 1/3 が決まる。左の 1/3 を出したまま中央へ滑らせると、左の 2/3 になる
- **Esc** を押すと、そのドラッグでは並ばない
- 並んだウィンドウを引き剥がすと、元の大きさに戻る
- ウィンドウの端を掴んで大きさを変えるドラッグでは並ばない。縦長の画面でも並ばない
- ホットコーナーを設定している角では、隅まで押し込むとホットコーナーも反応する。隅の少し手前で離す

### ほかのアプリや macOS の機能と一緒に使うとき

- **Rectangle** は同じキーを使う。One で足りるなら Rectangle を終了する。Rectangle を使い続けるなら、
  設定の「ウィンドウ」タブで「ショートカットで動かす」を切る（メニューから選んで動かすのは、切っても使える）
- **macOS の端へ寄せて並べる機能**（macOS 15 以降。システム設定 > デスクトップと Dock > ウィンドウ）と
  One のドラッグは、両方入れていると1回のドラッグに両方が反応する。どちらか一方にする
  （One のほうは、設定の「ウィンドウ」タブの「ドラッグで端に寄せて並べる」で切れる）

Rectangle にあって One に無いもの: 同じキーを続けて押して大きさを送る動き、ショートカットの変更、ウィンドウ同士の隙間。

## 鏡

ビデオ会議の前に、顔や髪を確かめるための鏡。

```
        ┌──────┐  ← ノッチをクリック
 ───────┴──────┴──────────────
      ┌──────────────┐
      │              │   鏡像で映る
      │    (・_・)    │   端を掴んで好きな大きさに
      │              │   外をクリック / Esc / ⌘W で閉じる
      └──────────────┘
```

- **開く** … MacBook のノッチをクリックする。⌘ を右クリックして「鏡を出す」でも開く（⌘ の下に出る）。
  ノッチの無い Mac や、蓋を閉じて外部ディスプレイだけで使っているときはこちら
- **閉じる** … 外をクリック、Esc、⌘W、もう一度ノッチをクリック。メニューバーの ⌘ を押しても閉じる
- 大きさは端を掴んで変えられ、次に開いたときもその大きさで出る
- 閉じるとカメラも止まる（緑のランプが消える）
- 開いても前面のアプリは変わらない。ビデオ会議のアプリを前に置いたまま使える

鏡の上で右クリックするか、設定の「鏡」タブで、カメラ・画質・鏡像にするか・外をクリックしても閉じないか・
ノッチのクリックで開くかを選べる。設定の窓を押しても鏡は閉じないので、「鏡を出して確かめる」で鏡を出したまま
画質を変えると、映りがその場で変わる。

画質は、自動 / 4K / 1080p / 720p / 540p / 480p から。今のカメラで使えない画質は選べない。
画質は「その程度で」とカメラに頼むもので、実際に何で映るかはカメラ次第。

## カレンダー

メニューバーの ⌘ を左クリックすると、⌘ の真下に月の表が出る。

```
 ┌─────────────────────────┐
 │ 2026年9月      ‹ 今日 › │
 │ 日 月 火 水 木 金 土    │
 │ 30 31  1  2  3  4  5    │
 │  …                      │   予定のある日に点
 │ 27 ㉘ 29 30  1  2  3    │
 ├─────────────────────────┤
 │ 9月28日(月)             │
 │ ▍会議   10:00–11:00     │   押すとカレンダー.app で開く
 └─────────────────────────┘
```

- 予定は、カレンダー.app に入っているアカウント（iCloud・Google・Exchange など）から読む
- 予定のある日には、そのカレンダーの色の点が付く。日を押すと、その日の予定が並ぶ
- 予定を押すとカレンダー.app で開く。「カレンダーを開く」でカレンダー.app を開く
- 日曜と祝日は赤、土曜は青
- 開くたびに今日の月に戻る。外をクリック、Esc、⌘W、もう一度 ⌘ を押すと閉じる
- 週の始まりは、システム設定 > 一般 > 言語と地域 に従う

**同期は要らない。** カレンダー.app と同じところから読んでいて、iCloud や Google との同期はカレンダー.app を
開いていなくても macOS がする。開いている間に予定が変われば、その場で描き直す。同期の間隔は、
カレンダー.app の設定 > アカウント の「カレンダーを更新」で変えられる。

設定の「カレンダー」タブで選べるもの:

- **左クリック** … カレンダーにするか、メニューにするか（もう一方は右クリック）
- **祝日のカレンダー** … ここで選んだカレンダーに終日の予定がある日を、赤くする。名前に「祝日」か「Holiday」が
  入ったカレンダー（「日本の祝日」など）があれば、はじめからそれが選ばれている
- **出すカレンダー** … アカウントごとにスイッチで選ぶ。祝日や誕生日を隠すなど。祝日のカレンダーを隠しても、
  祝日の赤は残る

## モニタ

メニューバーに、今の数字を小さく2段で出す。1秒ごとに書き換わる。1つでも出していると、⌘ の代わりに数字が
One の目印になる（クリックも同じように効く）。全部切ると ⌘ に戻る。

| 項目 | 出すもの |
| --- | --- |
| ネットワーク | Wi-Fi と有線を合わせた受信（↓）と送信（↑）の速度。VPN と Mac の中だけの通信は数えない |
| CPU | 全部のコアを合わせた忙しさ |
| メモリ | 使っている量の割合。アクティビティモニタの「使用済みメモリ」に合わせた数え方 |
| ディスクの空き | 起動ディスクの空き。macOS が空けられる分（一時ファイルなど）も含める |

⌘ を右クリックしたメニューの上のほうにも、同じ数字をもっと細かく（メモリの GB など）出す。
メニューを開いている間も書き換わる。

何を出すかは、設定の「モニタ」タブで、メニューバーとメニューのそれぞれに選ぶ。全部出すとメニューバーで
幅をとり、ノッチのある MacBook ではほかのアイコンが隠れることがある。メニューバーには少しだけ、メニューには
全部、のようにできる。どこにも出さない項目は測らない。ディスプレイが眠っている間も測らない。

温度と GPU の使用率は出さない。Apple が公開していない仕組みを使うことになるから。

## 設定

⌘ を右クリックして「設定…」（`⌘,`）。機能ごとのタブに分かれている。

| タブ | 選べること |
| --- | --- |
| 一般 | ログイン時に起動。アクセシビリティとカレンダーの許可があるか |
| 英かな | 左右の ⌘ に割り当てた入力ソース（見るだけ）、左右を入れ替える、メニューバーに A / あ も出す |
| ウィンドウ | ショートカットで動かす、ドラッグで端に寄せて並べる |
| 鏡 | カメラ、画質、鏡像にする、外をクリックしても閉じない、ノッチのクリックで開く |
| カレンダー | 左クリックで出すもの、祝日のカレンダー、出すカレンダー |
| モニタ | メニューバーに出すもの、右クリックのメニューに出すもの |

## うまく動かないとき

**「“One”は開いていません」「検証できませんでした」と出て開けない**
上の「入れる」の 2 を打つ。

**⌘ を押しても切り替わらない**
- 設定の「一般」タブで、アクセシビリティの許可が「あり」か見る
- 許可のスイッチは入っているのに動かないなら、許可の記録が古くなっている。一度消して与え直す:

  ```sh
  tccutil reset Accessibility com.finalize.one
  ```

  One を終了して開き直すと、また許可を聞かれる
- ⌘英かな のような、同じことをするアプリが動いていないか
- それでも駄目なら、システム設定 > プライバシーとセキュリティ >「入力監視」にも One を足してみる

**ショートカットでウィンドウが動かない**
- Rectangle など、同じキーを使うアプリが動いていないか
- 設定の「ウィンドウ」タブで「ショートカットで動かす」が入っているか
- アクセシビリティの許可があるか

**ドラッグで端に寄せても並ばない**
- 設定の「ウィンドウ」タブで「ドラッグで端に寄せて並べる」が入っているか
- アクセシビリティの許可があるか
- macOS の端へ寄せて並べる機能と取り合っていないか

**鏡が出ない・映らない**
- ノッチの無い Mac では、⌘ を右クリックして「鏡を出す」を使う
- 設定の「鏡」タブで「ノッチのクリックで開く」が入っているか
- 「カメラの使用が許可されていません」と出たら、鏡の中の「システム設定を開く」から One のカメラを許可する
- 「カメラが見つかりません」と出たら、カメラがつながっているか

**カレンダーに予定が出ない**
- 設定の「一般」タブで、カレンダーの許可が「あり」か見る。「フルアクセス」でないと読めない
- 設定の「カレンダー」タブで、そのカレンダーを切っていないか
- カレンダー.app に出ていない予定は、One にも出ない（同期の間隔はカレンダー.app の設定で）

**メニューバーに数字が出ない・アイコンが隠れる**
- 設定の「モニタ」タブで、メニューバーに出すものを選んでいるか
- 出すものが多いとメニューバーの幅が足りず、隠れることがある。減らす

**それでも分からないとき**
One は動いたことを記録している。ターミナルで次を打つと、直近2分ぶんが出る。困りごとを知らせるときに添えると早い:

```sh
log show --last 2m --predicate 'subsystem == "com.finalize.one"' --style compact
```

## やめる

1. ⌘ を右クリックして「One を終了」
2. `/Applications/One.app` をゴミ箱に入れる
3. ログイン時に起動を入れていたなら、システム設定 > 一般 > ログイン項目 から外す

許可の記録と設定も消すなら、ターミナルで:

```sh
tccutil reset All com.finalize.one
defaults delete com.finalize.one
```
